# HANDOFF 1.66.22

## What changed

1.66.22 puts DeepSeek on the usage surfaces and makes its money figure real. DeepSeek publishes exactly one money endpoint (`GET https://api.deepseek.com/user/balance`) and no spend or billing history, so the card shows what is left - total, plus the granted/topped-up split - and, beside it, what our own transcript records say the turns so far cost, priced at DeepSeek's published DeepSeek-V4-Flash rates. The balance endpoint stays the independent check. No migrations are included and task concurrency remains 5 (`PersonalTaskService.ts`).

- `apps/server/src/usage/usageTranscripts.ts` + `usageTranscriptReader.ts`: a `deepseek` provider kind. DeepSeek sessions run the Claude Agent SDK against DeepSeek's Anthropic-compatible endpoint, so their transcripts are Claude-format JSONL; the Claude parser is reused with the provider re-stamped, and only the provider decides the price.
- `apps/server/src/usage/UsageService.ts`: `resolveTranscriptDirs` reads DeepSeek instances' `<home>/projects` (the same resolver the driver runs sessions with: instance `homePath`, then an inherited `CLAUDE_CONFIG_DIR`, then `~/.claude-t3-deepseek`), and `deepseek` joins `SESSION_USAGE_PROVIDERS`, so the Team table attributes its turns to the bots that ran them. New `readDeepSeekSpend(projectsDir)`: the all-time API-price value of the records under that home, one pass over the same per-file cache as the scans, de-duplicated exactly as the aggregator does, `null` when there is nothing to price, and it never fails.
- `apps/server/src/usage/usagePricing.ts`: every DeepSeek record prices at the published Flash rates (input cache-miss $0.14/M, cache-hit $0.0028/M, output $0.28/M), keyed by provider kind rather than the LiteLLM table, because the picker offers Flash only; custom price overrides still win, as everywhere else. Cache writes have no separately published rate and bill as cache misses.
- `apps/server/src/provider/Layers/DeepSeekProvider.ts` + `Drivers/DeepSeekDriver.ts`: the probe carries the spend figure as `spent` on the usageBalance snapshot, independently of the balance read (a failed balance still shows it; a failed or absent scan shows the balance alone, never a zero). The driver wires the scan for the instance's own home; the built-in-driver layer needs `UsageService`, provided at the runtime level that already serves the personal bot token usage.
- `packages/contracts/src/providerUsageLimits.ts`, `usage.ts`: `ServerProviderSpend` on `ServerProviderUsageBalance` (additive; an older snapshot without it still decodes) and `UsageProviderKind` gains `deepseek` (`USAGE_CONTRACT_VERSION` 7).
- `apps/web/src/features/personal/usagePresentation.ts`: the DeepSeek card's balance view gains `spent`, and both money surfaces render one shared line, `Spent $0.76 since 8 Oct`, or `No DeepSeek spend recorded yet.` when there is nothing to price. The old `Spend is not tracked for DeepSeek yet.` sentence is replaced, since spend is now tracked.
- `apps/web/src/features/personal/PersonalUsageStrip.tsx` (usage sheet card), `TokenUsageSection.tsx` (Team card row), `components/usage/usageProviders.ts` and `tokenUsagePresentation.ts` (DeepSeek provider label, colour and bar in the usage page and the Team table).
- `apps/mobile/src/features/usage/usageProviders.ts`: the label/colour maps for the new kind, so the union stays exhaustive.
- `apps/server/src/personal/botTokenUsage.ts`: DeepSeek sessions attribute to their bots (`provider_name` `deepseek`, a Claude-shaped `resume` cursor).

## What was left out, and why

- **The two-up strip cell.** The strip is two percent windows with one shared "Session/Weekly percent used" shape, already tuned to fit a 280 px desktop column and 390 px phone; a third cell squeezes the existing two and reads as a window that never fills. The balance and the spent figure live one tap away in the sheet, and the Team card shows both too.
- **Upstream's /usage-limits panel and the composer chip.** Both render subscription windows; a money figure has no window to draw.
- **LiteLLM for DeepSeek pricing.** Deliberate: DeepSeek bills through its own rate card, so the figure must not move when LiteLLM changes, and it must price even with no rate table fetched.

# APK fixtures

Six APKs for the update verifier unit tests. They are signed by two throwaway
test keys generated by `scripts/make-fixtures.sh`. They are not signed by the
hbots release key and must never be published.

| File                     | What it proves                                           |
| ------------------------ | -------------------------------------------------------- |
| `good-1.66.112.apk`      | A correct APK passes every check.                        |
| `wrong-package.apk`      | Another package name is rejected.                        |
| `wrong-version-code.apk` | A versionCode that differs from the release is rejected. |
| `wrong-version-name.apk` | A versionName that differs from the release is rejected. |
| `wrong-signer.apk`       | A signer other than the compiled pin is rejected.        |
| `two-signers.apk`        | An APK with more than one signer is rejected.            |

Regenerating the fixtures creates new keys, so the pinned digest and the hashes
in `ApkVerifierTest` must be updated from the script's output.
